# LTA_DataMall_API_Output
JSON formatted outputs of Singapore Land Transport Authority DataMall API

### Queries Included:

* [Approved Road Works](approved_road_works.json)
* [Bicycle Parking](bicycle_parking.json)
* [Bus Routes](bus_routes.json)
* [Bus Services](bus_services.json)
* [Bus Stops](bus_stops.json)
* [Electric Vehicle Charging Batch](ev_charging_batch.json)
* [General Transit Feed Specification (GTFS) Schedule](gtfs_schedule)
* [Passenger Volume By Bus Stops](pv_bus)
* [Passenger Volume By Train Stations](pv_train)
* [Planned Bus Routes](planned_bus_routes.json)
* [Planned Road Openings](planned_road_openings.json)
* [Taxi Stands](taxi_stands.json)

Accurate as of 2026/09
